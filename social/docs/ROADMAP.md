# Build sequence

1. **Pilot foundation (this delivery):** two hosted paths, login/sign-up, separate database, private uploads, moderation, social interactions, following/private accounts, private DMs, focus lock, settings/deletion, admin, GitHub source and checks.
2. **Owner setup:** create the owner account; promote its exact ID through D1; connect verified email delivery; inspect the local/browser test results and production smoke checks.
3. **Small supervised trial:** the minimum age is 13, confirmed by self-declaration. Review every upload, test real devices, monitor Cloudflare free quotas, gather feedback and measure database latency. No paid upgrade is required to test the capped pilot. Youth-specific privacy and safety work is required before a wider launch.
4. **Content and safety:** staffed reports/appeals, moderator roles, rate-limit tuning, image re-encoding, video transcoding/scanning, copyright procedures, account recovery/MFA, accessibility review.
5. **Media growth:** optional private B2 multipart uploads are implemented; connect and test the provider, then add thumbnails and adaptive playback as needed. Long-form Videos remain deferred. The finite free storage budget supports a pilot, not YouTube-scale hosting.
6. **Commerce:** seller verification, payment-provider setup, Stripe Connect, server-verified checkout webhooks, fees, refunds, receipts, taxes, payouts and disputes. No card collection before these are complete.
7. **Public launch:** final brand, reviewed legal documents, moderation readiness, independent security assessment, load testing, privacy/export and retention procedures, observability, backup restore drills, supported mobile/PWA packaging.

Deferred: push notifications, mobile app-store builds, real-time WebSocket chat, collaborative communities, live streaming, long-form HD hosting, end-to-end encrypted messaging, public creator analytics and recommendation ranking. The current chronological system remains the baseline.
